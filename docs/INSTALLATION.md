# InvoiceFlow installation

The distributable is the complete onedir folder:

`dist\InvoiceFlow\InvoiceFlow.exe`

Copy the entire `dist\InvoiceFlow` folder to a Windows machine and launch `InvoiceFlow.exe`. Python, pip, an IDE and internet access are not required. The current release was built on Windows 11 with Python 3.15, PySide6 6.12.0, PyMuPDF 1.28.2 and PyInstaller 6.22.3.

For development, from `D:\Mlnew\InvoiceFlow` install the packages in `requirements.txt` and run `python main.py`.
