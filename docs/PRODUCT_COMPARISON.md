# Product comparison

| Capability | Conventional PDF-to-Excel workflow | InvoiceFlow 2.0 |
|---|---|---|
| Local PDF extraction | Usually manual or script-specific | Deterministic PyMuPDF engine |
| Batch ZIP processing | Often manual extraction | Safe nested ZIP processing |
| Duplicate awareness | Usually filename-based | File hash, normalized identity and weighted similarity |
| Review traceability | Often overwritten | Original values plus correction audit history |
| Financial checks | Manual spreadsheet checks | Deterministic validation and explainable anomaly alerts |
| Exports | One flat output | Excel summary/line items/issues, CSV and structured JSON |
| Privacy | Depends on service | Local-first processing by default |

This table describes verified InvoiceFlow capabilities only; it makes no unsupported claims about other products.
